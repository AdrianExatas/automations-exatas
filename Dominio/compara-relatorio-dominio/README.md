# Compara Relatorio Dominio

Aplicacao local em Streamlit para comparar dois PDFs:

- relatorio enviado pelo cliente;
- relatorio de saidas gerado pela Dominio.

## Requisitos

- Python 3.14+

## Instalar

```bash
pip install -e .[dev]
```

## Executar

```bash
streamlit run app.py
```

## Testar

```bash
pytest
```
