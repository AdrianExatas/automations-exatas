# Parcelamentos SEFAZ AL

Automacao em TypeScript + Playwright para coleta/consulta de parcelamentos na SEFAZ AL.

## Estrutura

- `src/`: fluxo principal e helpers
- `playwright.config.ts`: configuracao de execucao
- `output/`: artefatos locais

## Setup

```bash
npm install
```

## Comandos principais

```bash
npm test
npm run start
```

Use `npm run build` quando precisar gerar a versao compilada em `dist/`.
