# Glossário

| CPF | Cadastro de Pessoa Física |

| DJE | Documento para Depósitos Judiciais ou Extrajudiciais |

## Termos

Principais termos utilizadas no PAGTOWEB.

| Termo | Descrição |
| --- | --- |
| Código de receita | É o código através do qual o contribuinte pessoa física ou jurídica paga seus tributos federais |
| Cadastro Imobiliário Brasileiro (CIB) | São informações cadastrais de imóveis rurais e urbanas, públicos ou privados, inscritos nos respectivos cadastros de origem, como o Cadastro Nacional de Imóveis Rurais (CNIR) |
| Data de arrecadação | É a data contábil da efetivação do pagamento |
| Data de Vencimento | Data de vencimento do tributo |
| Desmembramentos | Os desmembramentos são os desdobramento dos tributos pagos em um único documento de arrecadação |
| Documento de Arrecadação | Documento de Arrecadação de Receitas Federais emitido para o pagamento de tributos federais (impostos, taxas e contribuições). O mesmo pode representar uma arrecadação efetivamente paga pelo contribuinte bem como um agendamento ou uma emissão de documento de arrecadação. Observação: Para esse serviço somente os documentos pagos serão disponibilizado |
| Extensão da Receita | É o código da extensão de receita que identifica datas de vencimentos ou alíquotas de um tributo dentro de um mesmo código de receita |
| Período de Apuração | Período de apuração do débito/tributo do pagamento |
| Receita principal | É o código de receita principal do tributo |
| Receita multa | É o código de receita de multa associada do tributo principal nos casos de pagamento em atraso |
| Receita juros | É o código de receita de Juros associado ao tributo principal nos casos de atualização monetária |
| Referencia | O número de referência no DARF é um código numérico que complementa a informação |
| Tipos de documento | Tipo do documento de arrecadação (DARF, DAS, DAE, DJE) |
| Valor Saldo Total | Valor não utilizado do pagamento |
