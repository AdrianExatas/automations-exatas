# Glossário

## Palavras

Glossário de palavras comumentes utilizadas.

| Palavra | Descrição |
| --- | --- |
| Outorgante | Pessoa física ou jurídica que emite uma procuração. |
| Outorgado | Pessoa física ou jurídica que recebe uma procuração de um outorgante. Também conhecido como procurador. |
| Procurador | Pessoa física ou jurídica que recebe uma procuração de um outorgante. Também conhecido como outorgado. |
| Data de expiração | Último dia de vigência de uma procuração eletrônica. |
| Procuração Ativa | Situação de uma procuração eletrônica ainda vigente. |
| Procuração Expirada | Situação de uma procuração eletrônica não mais vigente. |
| Procuração Cancelada | Situação de uma procuração eletrônica cancelada pelo outorgante ou procurador. |
