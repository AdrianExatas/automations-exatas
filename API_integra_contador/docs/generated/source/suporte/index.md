# Como pedir ajuda

Em caso de dúvidas, problemas na aplicação ou indisponibilidade, por favor, [clique aqui e abra um acionamento](https://centraldeajuda.serpro.gov.br/duvidas/pt/suporte/sup_integracontador/). Essa URL leva a um formulário web através do qual é possível solicitar suporte. Lembre-se de ter em mãos o CNPJ em nome do qual foi realizada a contratação.

Caso deseje segunda via de boleto, relatório de consumo, obter as chaves ou cancelar o contrato, acesse a [Área do Cliente](https://cliente.serpro.gov.br/).

**Central de Serviços Serpro**
