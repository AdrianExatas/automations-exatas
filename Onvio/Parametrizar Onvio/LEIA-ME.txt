AUTOMACAO ONVIO - GUIA DE USO
==============================

INSTALACAO
----------

1. Instale o Python:
   https://www.python.org/downloads/

2. Abra o PowerShell nesta pasta e execute:
   pip install -r requirements.txt

CONFIGURAR OS DADOS
-------------------

1. Edite o arquivo `dados.json`.

2. Estrutura esperada:

{
  "cnpj": "12345678000195",
  "departamentos": [
    {
      "departamento": "Auditoria",
      "usuario": "Bruno Costa"
    }
  ]
}

3. Ajuste os departamentos e usuarios conforme a empresa a ser parametrizada.

CREDENCIAIS DE LOGIN
--------------------

As credenciais de acesso ficam configuradas em `automacao.py`.
Se precisar altera-las localmente, edite os valores de `EMAIL_LOGIN` e `SENHA_LOGIN`.

EXECUTAR A AUTOMACAO
--------------------

Opcao 1 - Interface grafica:
  execute `interface.bat`

Opcao 2 - Linha de comando:
  execute `executar.bat`

Opcao 3 - PowerShell:
  python automacao.py

O QUE A AUTOMACAO FAZ
---------------------

1. Abre o Chrome e faz login no Onvio.
2. Navega ate a lista de clientes.
3. Pesquisa o CNPJ informado.
4. Abre a aba de departamentos da empresa.
5. Preenche os departamentos e usuarios definidos no `dados.json`.

CONFIGURACOES
-------------

Edite `automacao.py` para ajustar:

- `TEMPO_ESPERA`: intervalo entre acoes do navegador.

SOLUCAO DE PROBLEMAS
--------------------

- `Python nao encontrado`: instale o Python e marque `Add Python to PATH`.
- `selenium not found`: execute `pip install -r requirements.txt`.
- `TimeoutError`: aumente `TEMPO_ESPERA` no `automacao.py`.
- `CNPJ nao encontrado`: revise o valor configurado no `dados.json`.
- `Erro de login`: confirme as credenciais definidas localmente.
