📋 INSTALACAO (APENAS 1 VEZ)
═══════════════════════════════════════════════════════════════

1. Instalar Python (se ainda nao tiver):
   https://www.python.org/downloads/
   
   ⚠️ IMPORTANTE: Marque "Add Python to PATH" durante instalacao!

2. Abrir o PowerShell nesta pasta e executar:
   
   pip install -r requirements.txt


📊 CONFIGURAR OS DADOS
═══════════════════════════════════════════════════════════════

1. Editar o arquivo: dados.json

2. Estrutura:
   {
     "cnpj": "11188276000242",  ← CNPJ da empresa
     "departamentos": [
       {
         "departamento": "Auditoria",
         "usuario": "Pedro Henrique"
       },
       ...
     ]
   }

3. Para adicionar mais empresas (no futuro), criar estrutura com array


🔐 CREDENCIAIS DE LOGIN
═══════════════════════════════════════════════════════════════

EMAIL_LOGIN = 'adrian@exatascontabilidade.com.br'

🚀 EXECUTAR A AUTOMACAO
═══════════════════════════════════════════════════════════════

OPCAO 1 - INTERFACE GRAFICA (RECOMENDADO):
   Duplo clique em: interface.bat
   
   ✅ Permite alterar o CNPJ
   ✅ Visualiza todos os departamentos e usuarios
   ✅ Edita o JSON diretamente
   ✅ Executa a automacao com um clique

OPCAO 2 - Linha de comando (Simples):
   Duplo clique em: executar.bat

OPCAO 3 - PowerShell:
   python automacao.py


📝 O QUE A AUTOMACAO FAZ
═══════════════════════════════════════════════════════════════

ETAPA 1: LOGIN
  1. Abre o navegador Chrome
  2. Acessa https://onvio.com.br/login/#/
  3. Clica em "Continuar para login"
  4. Insere email
  5. Insere senha
  6. Aguarda login completar

ETAPA 2: NAVEGACAO ATE A EMPRESA
  1. Navega para dashboard Onvio
  2. Vai para lista de clientes (Gestta)
  3. Pesquisa pelo CNPJ
  4. Clica no link do CNPJ
  5. Acessa a aba de departamentos

ETAPA 3: PREENCHIMENTO
  Para cada departamento:
  1. Seleciona o departamento
  2. Seleciona o usuario
  3. Clica em "Adicionar"
  4. Repete para todos os registros


⚙️ CONFIGURACOES
═══════════════════════════════════════════════════════════════

Edite o arquivo automacao.py:

TEMPO_ESPERA = 1.5  ← Tempo entre acoes (em segundos)
                      Se a internet for lenta, aumente para 2 ou 3


🔧 SOLUCAO DE PROBLEMAS
═══════════════════════════════════════════════════════════════

Erro: "Python nao encontrado"
  └─ Instale Python e marque "Add to PATH"

Erro: "selenium not found"
  └─ Execute: pip install -r requirements.txt

Erro: "TimeoutError"
  └─ Aumente TEMPO_ESPERA no arquivo automacao.py
  └─ Verifique sua conexao de internet

Erro: "CNPJ nao encontrado"
  └─ Verifique se o CNPJ esta correto no dados.json
  └─ Verifique se voce tem acesso a esse cliente

Erro de Login
  └─ Verifique as credenciais no arquivo automacao.py
  └─ Teste fazer login manual primeiro
