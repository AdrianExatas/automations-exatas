# Parcelamentos SEFAZ BA

Automacao em TypeScript + Playwright para consulta de parcelamentos na SEFAZ BA.

## Estrutura

- `src/`: fluxo de automacao
- `model.xlsx`: modelo seguro versionado
- `output/`: artefatos locais

## Setup

```bash
npm install
```

## Comandos principais

```bash
npm test
npm run start
```

Use `npm run build` para gerar a saida compilada em `dist/`.
